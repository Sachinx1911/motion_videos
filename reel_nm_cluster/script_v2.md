# दीडशे स्क्वेअर फुटांचं घर, पाचशे होणार? नवी मुंबई cluster redevelopment वरची स्थगिती उठली
*SRS Dwell · 27 Oct 2026 · reel folder: `reel_nm_cluster` · draft v2 (script craft: questions, 5 hooks, open loops, retention) · approval pending*

## Audience questions (guesses, not from comments yet)
1. माझी building cluster मध्ये येते का?
2. नवीन घर किती मोठं मिळेल, पैसे भरावे लागतील का?
3. लगेच घर रिकामं करावं लागेल का?
4. Society मधले काही लोक नको म्हणाले तर?
5. Sign करण्याआधी काय तपासायचं?

## 5 hooks
1. Problem: तीस वर्षं जुनं सिडको घर, लहान जागा आणि वाढलेलं कुटुंब? नवी मुंबईत cluster redevelopment चा मार्ग पुन्हा खुला झाला आहे!
2. Curiosity: महापालिकेने थांबवलेलं cluster redevelopment, सरकारने पुन्हा सुरू केलं. तुमची building यात येते का?
3. Surprising fact (CHOSEN): दीडशे स्क्वेअर फुटांचं घर, थेट पाचशे स्क्वेअर फुटांचं? नवी मुंबईत cluster redevelopment वरची स्थगिती उठली आहे!
4. Mistake: Cluster redevelopment ला हो म्हणण्याआधी या तीन गोष्टी तपासल्या नाहीत, तर नंतर पस्तावाल!
5. Result: जुन्या सिडको घराच्या बदल्यात किमान तीनशे तेवीस स्क्वेअर फूट, आणि पंचवीस टक्के जास्त जागा मोफत! नवी मुंबईत cluster चा मार्ग पुन्हा खुला.

## Script v2 (voice)
[excited] दीडशे स्क्वेअर फुटांचं घर, थेट पाचशे स्क्वेअर फुटांचं? नवी मुंबईत cluster redevelopment वरची स्थगिती उठली आहे!

[serious] अकरा ऑगस्टला नवी मुंबई महापालिकेच्या महासभेने, संपूर्ण शहरात cluster redevelopment ला स्थगितीचा ठराव केला होता. पण पंधरा ऑक्टोबरला राज्याच्या नगरविकास विभागाने सांगितलं, राजपत्रात आलेले प्रस्ताव, असे थांबवता येणार नाहीत!

[curious] घणसोलीच्या Simplex वसाहतीत, तीन हजार दोनशे साठ माथाडी कुटुंबं, दीडशे स्क्वेअर फुटांच्या घरात राहतात. त्यांना पाचशे स्क्वेअर फुटांपेक्षा थोडं मोठं घर देण्याचं आश्वासन आहे. वाशी सेक्टर नऊ ची JN वसाहतही यात आहे.

[confident] पण तुमची building cluster मध्ये येईल का? Cluster म्हणजे अनेक इमारती एकत्र. UDCPR चा नियम चौदा पॉइंट आठ सांगतो, किमान दहा हजार चौरस मीटर जागा. इमारती तीस वर्षांपेक्षा जुन्या, किंवा धोकादायक. आणि एक्कावन्न टक्के जागेच्या मालकांची संमती. अशा cluster ला चार FSI मिळू शकतो.

[excited] आणि तुम्हाला किती मोठं घर मिळेल? हा आकडा नियमातच लिहिला आहे. अधिकृत इमारतीतल्या रहिवाशाला किमान तीस चौरस मीटर, म्हणजे जवळपास तीनशे तेवीस स्क्वेअर फूट. आणि त्यावर पंचवीस टक्के जास्त जागा, तीही मोफत!

[serious] पण इथे एक मोठा पण आहे. या प्रस्तावांना अजून राज्य सरकारची अंतिम मंजुरी लागेल. आणि सहा महिन्यांत महापालिका, रस्ते, पाणी आणि parking वरचा परिणाम तपासणार आहे. म्हणजे लगेच हातोडा पडणार नाही.

[confident] म्हणून cluster ला हो म्हणण्याआधी तीन गोष्टी तपासा. तुमची इमारत तीस वर्षांपेक्षा जुनी आहे का? Cluster ची एकूण जागा किती आहे? आणि करारात तुमचं घर किती स्क्वेअर फूट लिहिलं आहे?

[excited] तुमची building किती वर्षं जुनी आहे? Comment मध्ये लिहा! हा video नवी मुंबईतल्या मित्रांना पाठवा, आणि अशाच माहितीसाठी आमच्या पेजला फॉलो करा!
