# PRODUCTION LIBRARY

Reference menu. Never use everything in one video. Pick 1 primary style, 2-4 secondary, occasional accents.

---

## 1. CONTENT TYPES

Explainer, Educational, News / Current Affairs, Government Information, Documentary, Storytelling, Listicle, Comparison, Process, Case Study, Data Story, Myth vs Fact, Before vs After, Step-by-Step, Promotional, Product / Service, Location, Timeline.

## 2. STORY STRUCTURES

1. Problem → Solution
2. Question → Answer
3. Hook → Explanation → Takeaway
4. Before → After
5. Myth → Fact
6. N Things (listicle)
7. Step-by-Step
8. Timeline
9. Comparison
10. Case Study
11. News Update
12. Cause → Effect
13. What → Why → How
14. Mistake → Consequence → Correct Method
15. Situation → Problem → Evidence → Solution
16. Definition → Example → Application

## 3. HOOK MECHANISMS

Strong fact, surprising number, question, contradiction, common mistake, visual reveal, before/after, problem, curiosity gap, important warning, unexpected comparison, direct benefit.
